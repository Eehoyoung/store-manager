# 골든셋 변경 이력

라벨을 바꾸는 것은 **채점 기준 자체를 바꾸는 일**이다. 조용히 바꾸면 이후의 모든 수치가
무의미해지므로, 무엇을 왜 바꿨는지 여기 남긴다. 근거는 항상 `docs/12` 이며, 모델 출력이
아니다 — 모델에 맞춰 기준을 옮기면 평가가 자기 자신을 채점하게 된다.

## 2026-08-30 (v1.7 실측 후 재판정)

### 유료 결과 확인 후 라벨을 다시 판단하는 규범

골든셋을 모델·키워드 룰의 정답에 맞추지 않는다. 유료 실행 결과를 본 뒤 라벨을 바꾸는 것은
다음을 모두 만족할 때만 허용한다.

1. 근거가 모델 출력과 독립적이어야 한다. `docs/12`의 정의, 문장 전체의 화행·문맥 또는 확정된
   법령으로 설명하고, "모델이 그렇게 예측했다"를 근거로 쓰지 않는다.
2. 어떤 결과를 본 뒤 무엇을 바꿨는지 이 문서에 숨김없이 남긴다.
3. 변경이 게이트를 쉽게 만드는 방향이면 두 번째 검토자는 **대상 모델의 예측·점수와 변경 방향을
   보지 않고**, 문장과 적용 정의만으로 같은 라벨에 도달해야 한다. 독립 판정이 일치하지 않으면
   정답으로 고정하지 않고 경계 사례로 남긴다.
4. 게이트 기준값(카테고리 90%, 재현율 95%, 차단 누락 0건)은 라벨 변경과 무관하게 낮추지 않는다.

`G-0562` 는 게이트를 **쉽게 만드는 방향**이라 규범 3번이 요구하는 독립 판정 대상이었다.

두 검토자의 **최초 판정은 둘 다 risk 1** 이었다.

독립 판정했다. 결과는 risk 2** — 의견형 문장이지만 점주에게 환불이 정당하다고 말하는 요구다.

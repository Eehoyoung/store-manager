## 1. 총칙

소담(이하 "회사")은 ReviewPilot(리뷰파일럿) 서비스를 운영하며, 정보주체의 개인정보를 중요하게
생각하고 「개인정보 보호법」 등 관계 법령을 준수합니다. 회사는 이 방침을 통해 어떤 개인정보를
어떤 목적으로 처리하고 어떻게 보호하는지 알려드립니다.

**이 서비스는 사업자(가맹점)를 대상으로 하는 B2B 서비스입니다.** 다만 서비스의 성격상 회사는
**서비스 회원이 아닌 리뷰 작성자의 정보도 처리**합니다. 이에 관하여는 §5에서 별도로 설명합니다.

**이 서비스는 두 개의 채널로 동작하며 처리 방식이 서로 다릅니다.**

| | 배달 플랫폼 (배민·요기요·쿠팡이츠) | 방문 리뷰 플랫폼 (네이버 스마트플레이스) |
|---|---|---|
| 접속 주체 | 회사의 위탁을 받은 수탁자가 회원 계정으로 접속 | **회사는 접속하지 않습니다.** 회원 브라우저의 확장 프로그램만 동작 |
| 로그인 정보 | 회원이 위임하여 암호화 보관(§2.2) | **수집하지 않습니다**(§2.2의2) |
| 리뷰 본문 | 서버에 저장 | **서버에 저장하지 않습니다** |
| 답글 등록 | 안전검사를 통과하면 회사가 등록 | **회원이 직접 누릅니다** |

## 2. 처리하는 개인정보 항목

### 2.1 회원(가맹점주)

| 구분 | 항목 | 수집 시점 | 필수/선택 |
|------|------|----------|:---:|
| 계정 | 이메일, 비밀번호(단방향 해시 저장) | 회원가입 | 필수 |
| 신원 | 이름 | 회원가입 | 필수 |
| 연락처 | 전화번호 | 회원가입 | **선택** |
| 매장 | 매장명, 매장 주소 | 회원가입 | 필수 |
| 소속 | 가맹코드 | 회원가입 | **선택** (§4 참고) |
| 이용기록 | 접속 일시, 서비스 이용 기록, 감사 로그 | 서비스 이용 시 자동 | 필수 |

> **비밀번호는 복호화할 수 없는 형태(단방향 해시)로 저장**되며 회사도 원문을 알 수 없습니다.
>
> **사업자등록번호는 현재 수집하지 않습니다.** 향후 세금계산서 발행 등을 위해 수집하게 되는 경우
> 이 방침을 개정하고 별도 동의를 받습니다.

### 2.2 배달 플랫폼 계정정보 ★특별 관리 대상

| 항목 | 내용 |
|------|------|
| 수집 항목 | 배달 플랫폼 로그인 아이디, 로그인 비밀번호 |
| 수집 목적 | 회원 매장의 리뷰 조회 및 답글 등록 대행 |
| 저장 방식 | **AES-256-GCM 봉투암호화**. 비밀번호 원문은 데이터베이스·로그·오류 메시지 어디에도 저장하지 않습니다 |
| 접근 기록 | 복호화하여 사용할 때마다 **감사 로그에 기록**합니다 |
| 삭제 | 회원이 플랫폼 연동을 해제하거나 이용계약이 종료되면 파기합니다 |

> **이는 회원 본인의 계정정보이며, 회원의 위임에 따라 회사가 보관·사용합니다.**
> 회사는 이 정보를 리뷰 조회·답글 등록 외의 목적으로 사용하지 않습니다.

### 2.2의2 방문 리뷰 플랫폼 — 수집하지 않는 것 ★

| 항목 | 내용 |
|------|------|
| **수집하지 않는 정보** | **네이버 스마트플레이스의 아이디·비밀번호·쿠키·로그인 세션.** 회사는 이 중 어느 것도 받지 않으며 저장하지 않습니다 |
| 동작 방식 | 회원이 자신의 브라우저에 설치한 확장 프로그램이, 회원이 이미 로그인해 열어 둔 사장님 화면 안에서만 동작합니다 |
| 회사 서버로 전달되는 것 | 브라우저 안에서 작성자 표시·연락처를 가린 뒤의 **별점·주문 메뉴·리뷰 식별값과, 답글 생성에 필요한 비식별 입력**뿐입니다 |
| **리뷰 본문** | **서버에 저장하지 않습니다.** 답글 생성에 사용한 뒤 보관하지 않으며, 이를 담을 컬럼 자체를 두지 않았습니다 |
| 답글 등록 | 확장 프로그램은 답글을 입력란에 넣어 둘 뿐이며, **등록은 회원이 직접 누릅니다** |

> 방문 리뷰 채널에는 **자동 게시가 없습니다.** 따라서 회원의 확인 없이 답글이 게시되는 경로가
> 존재하지 않습니다.

### 2.3 리뷰 작성자(비회원 정보주체) ★§5에서 상세 설명

| 작성자 식별값 | 닉네임에 회사 고유 비밀값을 결합한 **단방향 해시**. 동일인 판별에만 사용하며 원문 복원 불가 |
| 리뷰 본문 | 배달 플랫폼: 원문 저장 / **방문 리뷰 플랫폼: 저장하지 않음**(§2.2의2) |
| 별점 | 원문 저장 |
| 주문 메뉴 | 원문 저장 |
| 첨부 사진 | 배달 플랫폼이 제공한 이미지 주소 저장 |
| 작성일 | 원문 저장 (배달 플랫폼이 날짜만 제공하며 시각은 제공하지 않습니다) |
| 기존 답글 | 회원이 이전에 직접 작성한 답글 (말투 학습용) |

## 4. 개인정보의 제3자 제공

### 4.1 가맹본부에 대한 제공

회원이 가맹코드를 입력하고 회사가 소속을 승인한 경우, 회사는 회원의 선택 동의를 근거로 아래 정보를
해당 가맹본부에 제공합니다.

| 구분 | 내용 |
|------|------|
| 제공받는 자 | 회원이 가맹계약을 체결한 프랜차이즈 가맹본부 |
| 제공 목적 | 브랜드 단위 운영 현황 파악 및 가맹점 지원 |
| 제공 항목 | 매장명·주소, 서비스 이용 상태, 플랫폼 연동 상태, 최근 수집 시각, 최소 집계 기준을 충족한 별점·분류·이슈·답글 처리 통계 |
| 제공 시점 | 회사가 소속 승인을 완료한 시점부터 |
| 보유·이용 기간 | 회원이 동의를 철회하거나 소속이 해제되거나 이용계약이 종료될 때까지 |

**가맹본부에 제공하지 않는 정보**

- 개별 리뷰 본문·사진·주문 메뉴·작성일, 작성자 표시·식별값
- 특정 리뷰를 유추할 수 있는 위험 사유나 상세 분석 결과
- 회원의 이메일·전화번호·사업자 정보와 구독·청구·입금 내역
- 배달 플랫폼 아이디·비밀번호 등 계정정보

회사는 적은 건수, 짧은 기간 또는 희귀한 조건의 조합으로 특정 리뷰 작성자를 다시 알아볼 수 없도록
최소 집계 기준을 적용합니다. 가맹본부는 조회만 할 수 있고, 승인된 소속 매장만 조회할 수 있으며,
모든 조회는 감사 로그에 기록됩니다.

### 4.2 동의를 거부할 권리와 거부 시 불이익

가맹코드 입력과 가맹본부 제공 동의는 선택사항입니다. 동의하지 않아도 리뷰 수집, 답글 생성·게시,
매장 조회·통계 등 가맹본부 조회를 제외한 서비스 기능과 요금에는 차이가 없습니다. 회원은 언제든지
소속 해제와 동의 철회를 요청할 수 있습니다.

### 4.3 그 밖의 제3자 제공

회사는 위 경우를 제외하고 정보주체의 동의나 법령상 근거 없이 개인정보를 제3자에게 제공하지
않습니다. 수사기관 등의 요청이 있더라도 법령에 정한 권한과 절차를 확인한 범위에서만 제공합니다.

## 5. 리뷰 작성자에 대한 처리

### 5.1 처리 구조

회사는 **회원(가맹점)의 위임을 받아** 그 매장에 게시된 리뷰를 수집합니다. 리뷰 작성자는 회사의
회원이 아니며, **회사와 직접적인 접점이 없습니다.** 회사는 리뷰 작성자의 연락처를 알지 못하며
개별적으로 연락할 수단도 없습니다.

### 5.2 가명처리

**회사는 리뷰 작성자의 닉네임을 원문 그대로 저장하지 않습니다.**

| 단계 | 처리 |
|------|------|
| 1. 수집 | 배달 플랫폼에서 리뷰와 닉네임을 조회합니다. 배달의민족은 닉네임이 마스킹되지 않은 원문으로 전달됩니다 |
| 2. 가명처리 | **저장 직전에** 닉네임의 첫 글자를 제외한 나머지를 마스킹 처리합니다 (예: `히리릴` → `히**`) |
| 3. 식별값 생성 | 닉네임에 회사만 아는 비밀값을 결합하여 단방향 해시를 생성합니다. 동일인 판별에만 사용하며 원문을 복원할 수 없습니다 |
| 4. 원문 폐기 | 원문 닉네임은 저장하지 않으며, 로그·오류 메시지에도 남기지 않습니다 |

요기요·쿠팡이츠는 배달 플랫폼이 이미 마스킹한 형태로 전달하며, 회사는 그 형태를 그대로 유지합니다.

**방문 리뷰 플랫폼은 마스킹이 두 번 일어납니다.** 회원의 브라우저가 회사 서버로 보내기 **전에**
1차로 가리고, 서버가 받은 뒤 2차로 한 번 더 가립니다. 회사는 두 방어선 중 어느 하나도 다른 하나가
있다는 이유로 제거하지 않습니다.

### 5.3 처리의 범위와 근거

1. 회사는 회원이 적법하게 열람할 수 있는 자기 매장의 리뷰에 한해 회원의 위탁을 받아 조회·정리하고
   답글 작성 업무를 지원합니다.
2. 공개된 개인정보라도 공개 목적과 정보주체가 객관적으로 예상할 수 있는 범위를 벗어나 자유롭게
   이용할 수 있는 것은 아닙니다. 회사는 답글 처리와 매장 운영에 필요한 최소 범위만 처리합니다.
3. 회사는 리뷰 작성자의 권리보다 회사와 회원의 정당한 이익이 명백히 우선하는지 처리 목적·필요성·
   침해 가능성·안전조치를 문서화하여 정기적으로 검토합니다. 그 요건을 충족하지 못하는 처리는
   중단합니다.
4. 원문 닉네임은 저장 전에 가명처리하며, 가명정보를 익명정보로 취급하지 않습니다.

### 5.4 리뷰 작성자의 권리 행사

리뷰 작성자는 자신의 리뷰와 관련하여 회사에 열람·정정·삭제·처리정지를 요청할 수 있습니다.
다만 회사는 리뷰 작성자를 식별할 수단을 보유하지 않으므로, 요청 시 **해당 리뷰를 특정할 수 있는
정보(배달 플랫폼, 매장명, 리뷰 작성일, 리뷰 내용 등)**를 함께 제공해 주셔야 처리가 가능합니다.

**배달 플랫폼에 게시된 리뷰 원본의 삭제는 해당 배달 플랫폼에 요청하셔야 합니다.** 회사는 배달
플랫폼의 리뷰를 삭제할 권한이 없습니다.

### 6.1 재위탁 구조에 대한 고지 ★

**회사가 위탁받은 회원의 배달 플랫폼 계정정보는 수탁자(기웅정보통신)에게 전달되어 실제 배달
플랫폼 접속에 사용됩니다.**

```
회원 ──위임──▶ 회사 ──위탁──▶ 기웅정보통신(주) ──접속──▶ 배달 플랫폼
              (암호화 보관)      (조회·등록 대행)
```

- 회사는 수탁자에게 위탁 업무 수행에 필요한 최소한의 정보만 전달합니다.
- 회사는 수탁 계약 시 개인정보 보호 관련 의무를 명시하고 수탁자를 관리·감독합니다.
- 위탁 업무 또는 수탁자가 변경되는 경우 이 방침을 통해 공개합니다.

### 6.2 AI 처리에 관한 고지

## 9. 정보주체의 권리와 행사 방법

### 9.1 권리

| 정정·삭제 | 사실과 다른 정보의 수정 또는 삭제 요구 |

### 9.2 행사 방법

- **서비스 화면**을 통해 직접 조회·수정할 수 있는 항목: 이름, 전화번호, 비밀번호, 매장 정보
- 그 밖의 요청: 개인정보 보호책임자에게 서면·전자우편으로 요청
- 회사는 요청을 받은 날부터 **10일 이내**에 처리하고 결과를 통지합니다.
- 법정대리인 또는 위임을 받은 자를 통해서도 요청할 수 있으며, 이 경우 위임장을 제출해야 합니다.

### 9.3 가맹본부 제공에 대한 동의 철회

회원은 언제든지 회사에 **가맹본부 소속 해제**를 요청할 수 있습니다. 해제 시 이후 해당 가맹본부의
조회는 중단됩니다. 요청은 개인정보 보호책임자 또는 고객문의를 통해 접수합니다.

### 9.4 권리 행사의 제한

법령에 따라 열람·정정·삭제·처리정지가 제한되는 경우, 회사는 그 사유를 통지합니다.

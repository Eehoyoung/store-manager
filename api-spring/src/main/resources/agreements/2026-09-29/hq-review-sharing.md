# 가맹본부 개별 리뷰 제공 동의 (선택)

문서 버전: 2026-09-29

> ⚠ **법무 검토 전 초안입니다.** 변호사 검토가 끝나기 전에는 이 동의를 근거로 개별 리뷰 제공
> 기능을 실제로 켜지 않습니다(`app.hq.review-access-enabled` 기본값 false).

## 이 동의는 무엇이 다른가요

가입할 때 하신 "가맹본부 제3자 제공 동의"는 **매장의 운영 현황과 집계 통계**만 본부에 보여
드리는 동의입니다. 이 동의는 그것과 **별개로**, 본부가 **개별 리뷰의 내용까지** 볼 수 있게
하는 동의입니다. 이 동의를 하지 않으면 본부는 지금처럼 집계 화면만 계속 볼 수 있고, 개별
리뷰는 볼 수 없습니다.

이 기능은 회사가 실제로 켜기 전까지는 존재하지 않습니다. 동의하셔도 회사가 켜지 않으면
아무 일도 일어나지 않습니다.

## 제공받는 곳

가맹코드로 소속이 승인된 **바로 그 가맹본부**입니다. 다른 브랜드나 제3자에게는 제공되지
않습니다.

## 제공 목적

가맹본부가 매장 단위 리뷰 내용을 확인해 가맹점 지원·품질 관리에 참고하기 위함입니다.

## 제공 항목

| 항목 | 내용 |
|---|---|
| 매장명·플랫폼 | 어느 매장의 어느 배달앱/방문 채널 리뷰인지 |
| 작성일·별점 | 리뷰가 달린 날짜와 별점 |
| 리뷰 원문 | 손님이 남긴 리뷰 본문 |
| 작성자 표시 | 개인을 알아볼 수 없도록 가려진 표시(예: "김**"). 원래 닉네임이나 재식별 가능한
  내부 값은 제공하지 않습니다 |
| 분석 결과 | 회사 AI가 판정한 카테고리·이슈 태그·위험도·위험 사유 |
| 답글 처리 상태 | 검수 대기·차단·게시완료 등 진행 상태 |

**제공하지 않는 항목** — 작성자를 다시 알아볼 수 있는 내부 식별값, 사장님의 이메일·전화번호
등 개인정보, 배달 플랫폼 로그인 정보·주문번호, 요금·청구·입금 내역, 리뷰 사진 원본.

## 본부가 할 수 없는 것

**본부는 보기만 할 수 있습니다.** 답글을 수정·승인·거절하거나 매장 설정을 바꿀 수 없고,
개별 리뷰를 파일로 내려받아 일괄 반출할 수도 없습니다. 본부가 언제 어떤 리뷰를 봤는지는
모두 기록에 남습니다.

## 보유 및 제공 기간

이 동의를 유지하고 가맹본부 소속이 유지되는 동안만 제공됩니다. 다음 중 하나라도 해당하면
**그 즉시** 제공이 멈춥니다.

- 아래 방법으로 이 동의를 철회하신 경우
- 가맹본부 소속이 해제된 경우(사장님 요청 또는 회사의 처리)
- 이용계약이 종료된 경우

## 동의하지 않을 권리와 불이익

**동의하지 않으셔도 됩니다.** 동의하지 않거나 나중에 철회하셔도 리뷰 수집, 답글 자동 생성,
자동 게시 등 **서비스의 모든 기능을 똑같이** 이용하실 수 있고 요금도 같습니다. 회사가 드리는
불이익은 없습니다. 다만 본부와 맺으신 가맹계약에 별도로 정해진 내용이 있을 수 있으며, 그
부분은 회사가 관여하지 않습니다.

## 철회 방법

설정 화면의 "가맹본부" 섹션에서 언제든 철회할 수 있습니다. 철회 즉시 본부의 개별 리뷰 조회가
차단되며, 본부는 이후 집계 화면으로만 매장 현황을 확인합니다.

## 제1조 (목적)

이 약관은 〇〇(이하 "회사")가 제공하는 배달 플랫폼 리뷰 답글 자동화 서비스(이하 "서비스")의
이용과 관련하여 회사와 이용자 사이의 권리·의무 및 책임사항을 정함을 목적으로 합니다.

---

## 제2조 (정의)

| 용어 | 정의 |
|------|------|
| **서비스** | 배달 플랫폼에 게시된 리뷰를 수집하고, 인공지능으로 사장님 답글 초안을 생성하여 회원의 배달 플랫폼 계정으로 등록하는 서비스 |
| **회원** | 이 약관에 동의하고 회사와 이용계약을 체결한 **사업자**. 서비스는 사업자를 대상으로 하며 일반 소비자를 대상으로 하지 않습니다 |
| **매장** | 회원이 서비스에 등록한 개별 영업장. **요금·구독·이용 단위는 매장입니다** |
| **배달 플랫폼** | 배달의민족, 요기요, 쿠팡이츠 등 회원이 입점한 외부 주문·배달 플랫폼 |
| **플랫폼 계정정보** | 회원이 배달 플랫폼에 접속하기 위한 아이디·비밀번호 |
| **답글** | 리뷰에 대한 사장님(사업자) 명의의 댓글. **회사는 리뷰 본문을 생성하지 않습니다** |
| **자동 게시** | 생성된 답글이 회사의 안전검사를 통과하여 회원의 개별 확인 없이 배달 플랫폼에 등록되는 것 |
| **위험 리뷰** | 위생·이물질·식중독·법적분쟁 등 회사의 판정 기준상 위험도가 높은 리뷰 |
| **가맹본부** | 회원이 가맹계약을 체결한 프랜차이즈 본부로서, 회사로부터 별도 계정을 발급받은 자 |
| **가맹코드** | 가맹본부가 소속 가맹점에 배포하는 코드. 회원이 이를 입력하고 회사가 승인하면 해당 매장의 정보가 가맹본부 조회 대상이 됩니다 |
| **결제대행사** | 회사가 이용하는 결제 서비스 제공자(Groble). 결제는 결제대행사가 제공하는 결제창에서만 이루어집니다 |

## 제3조 (약관의 게시와 개정)

1. 회사는 이 약관을 서비스 초기 화면 또는 연결 화면에 게시합니다.
2. 회사는 관련 법령을 위배하지 않는 범위에서 이 약관을 개정할 수 있습니다.
3. 약관을 개정할 경우 회사는 적용일자와 개정사유를 명시하여 **적용일 7일 전부터** 공지합니다.
   다만 회원에게 불리한 변경의 경우 **적용일 30일 전부터** 공지하고, 회원이 알 수 있도록
   전자우편 등으로 개별 통지합니다.
4. 회원이 개정약관 적용일까지 거부 의사를 표시하지 않으면 개정약관에 동의한 것으로 봅니다.
   개정약관에 동의하지 않는 회원은 이용계약을 해지할 수 있습니다.

## 제4조 (이용계약의 체결)

1. 이용계약은 회원이 되고자 하는 자가 이 약관에 동의하고 회사가 정한 가입 절차를 완료한 때
   성립합니다.
2. 회원가입 시 회사는 이름, 이메일, 전화번호(선택), 매장명, 매장 주소를 수집합니다.
   구체적 항목과 처리 목적은 **개인정보처리방침(문서 17)**을 따릅니다.
3. 회사는 다음 각 호에 해당하는 신청에 대하여 승낙을 거부하거나 사후에 이용계약을 해지할 수
   있습니다.
   - 타인의 명의·정보를 도용한 경우
   - 사업자가 아닌 자가 신청한 경우
   - 자신이 정당한 권한을 갖지 않는 매장 또는 배달 플랫폼 계정으로 신청한 경우
   - 서비스 운영을 고의로 방해하거나 법령·이 약관을 위반한 이력이 있는 경우
4. 회사는 서비스 설비의 여유가 없거나 기술적·업무상 필요한 경우 승낙을 유보할 수 있습니다.

## 제5조 (서비스의 내용)

회사가 제공하는 서비스는 다음과 같습니다.

| 구분 | 내용 |
|------|------|
| 리뷰 수집 | 회원이 위탁한 배달 플랫폼 계정정보로 해당 매장의 리뷰를 주기적으로 조회·저장 |
| 답글 생성 | 수집된 리뷰를 인공지능으로 분류·분석하고 **사장님 답글 초안 1건**을 생성 |
| 안전검사 | 금칙어·보상약속·개인정보 노출·위험도 등을 검사하여 게시 가부를 판정 |
| 답글 등록 | 안전검사를 통과한 답글을 회원의 배달 플랫폼 계정으로 등록 |
| 조회·통계 | 매장별 리뷰·별점·응답 현황 조회 및 집계 지표 제공 |
| 가맹본부 조회 | 제10조의 요건을 충족한 경우 가맹본부에 조회 전용 화면 제공 |

**회사가 제공하지 않는 것**

- 회사는 **리뷰 본문을 생성·수정·삭제하지 않습니다.** 리뷰 조작은 표시·광고의 공정화에 관한
  법률 및 전자상거래법 위반이며, 회사는 이를 어떠한 형태로도 수행하지 않습니다.
- 회사는 별점·순위·노출 순서에 관여하지 않습니다.
- 회사는 배달 플랫폼의 운영자가 아니며, 배달 플랫폼의 정책·기능·장애에 관하여 권한이 없습니다.

## 제6조 (AI 생성 답글의 성격과 한계)

1. **답글은 인공지능이 생성한 초안입니다.** 회사는 답글의 내용이 회원의 의사와 완전히 일치함을
   보증하지 않습니다.
2. **답글은 회원(사업자)의 명의로 게시되며, 게시된 답글에 대한 대외적 책임은 회원에게 귀속됩니다.**
   회원은 이 점을 인지하고 서비스를 이용합니다.
3. **답글 게시는 되돌릴 수 없습니다.** 배달 플랫폼이 답글 수정·삭제 기능을 회사에 제공하지 않기
   때문입니다. 회사는 회원의 요청이 있더라도 이미 게시된 답글을 회사 시스템을 통해 수정하거나
   삭제할 수 없습니다. 수정·삭제가 필요한 경우 회원이 해당 배달 플랫폼의 사장님 화면에서 직접
   처리해야 합니다.
4. **위험 리뷰는 자동 게시되지 않습니다.** 회사는 위생·이물질·식중독·법적분쟁 등에 해당한다고
   판정한 리뷰에 대해서는 답글을 자동으로 게시하지 않고 차단 상태로 보관합니다. 이 경우 회원이
   해당 배달 플랫폼에서 직접 답글을 작성할 수 있습니다.
5. **차단 판정은 회사의 안전장치일 뿐 법적 판단이 아닙니다.** 차단되지 않았다는 사실이 해당
   리뷰에 법적 위험이 없음을 의미하지 않으며, 차단되었다는 사실이 리뷰 내용이 사실임을 의미하지도
   않습니다.
6. 회사는 답글에 **금전적 보상(환불·무상 제공·보상금 등)을 약속하는 문구를 생성하지 않습니다.**
   회원이 직접 입력한 문구는 회원의 책임입니다.
7. 회사는 답글 자동 생성·게시 과정에서 발생할 수 있는 오류를 줄이기 위해 노력하나, 생성 결과가
   항상 적절함을 보증하지 않습니다. 회원은 서비스가 제공하는 조회 화면을 통해 게시 내역을 주기적으로
   확인할 것을 권장합니다.

## 제7조 (회원의 의무)

1. 회원은 다음 사항을 준수합니다.
   - **자신이 정당한 이용 권한을 가진 매장과 배달 플랫폼 계정만 등록할 것.** 타인의 계정 또는
     타인이 운영하는 매장을 등록해서는 안 됩니다.
   - 등록한 계정정보를 정확하게 유지하고, 비밀번호 변경·계정 정지 등 변경사항이 발생하면 지체 없이
     서비스에 반영할 것
   - 자신이 이용하는 배달 플랫폼의 이용약관·운영정책을 준수할 것
   - 서비스를 통해 게시되는 답글의 내용이 관계 법령에 위배되지 않도록 관리할 것
2. **계정정보가 정확하지 않아 발생하는 문제는 회원의 책임입니다.** 잘못된 계정정보로 인한 로그인
   실패, 수집 중단, 배달 플랫폼의 계정 잠금 등에 대해 회사는 책임지지 않습니다.
3. 회원은 서비스를 이용하여 리뷰를 조작하거나, 경쟁 사업자를 비방하거나, 소비자를 기만하는 행위를
   해서는 안 됩니다.
4. 회원은 자신의 서비스 계정을 제3자와 공유해서는 안 됩니다.

## 제8조 (배달 플랫폼 정책과 책임 소재)

1. 서비스는 회원이 위탁한 계정정보를 이용하여 **회원을 대신하여 배달 플랫폼에 접속**합니다.
   이는 회원의 위임에 따른 대행 행위입니다.
2. **배달 플랫폼의 이용약관·운영정책이 제3자 도구를 이용한 자동 접속·자동 게시를 제한하거나
   금지할 수 있습니다.** 회사는 개별 배달 플랫폼이 이 서비스의 이용을 허용하는지에 관하여
   보증하지 않습니다.
3. 회원은 자신이 이용하는 배달 플랫폼의 정책을 확인할 책임이 있으며, 정책 위반을 이유로 배달
   플랫폼이 회원에게 계정 정지·제재·불이익 조치를 하는 경우 회사는 이에 대해 책임지지 않습니다.
   다만 회사의 고의 또는 중대한 과실로 인한 경우는 그러하지 아니합니다.
4. 배달 플랫폼이 API·화면 구조·정책을 변경하여 서비스의 전부 또는 일부를 제공할 수 없게 되는 경우,
   회사는 이를 회원에게 통지하고 해당 기능의 제공을 중단하거나 변경할 수 있습니다. 이 경우 제9조에
   따른 요금 정산을 합니다.
5. 회원이 배달 플랫폼과 사이에서 발생시킨 분쟁은 회원과 해당 배달 플랫폼 사이에서 해결합니다.

## 제9조 (이용요금과 결제)

### 9.1 요금

| 항목 | 내용 |
|------|------|
| 요금 | **매장당 월 30,000원 (VAT 별도)** |
| VAT 포함 | **33,000원** |
| 과금 단위 | 매장 단위. 매장 수만큼 요금이 발생합니다 |
| 결제 주기 | 월 단위 정기 결제 |

### 9.2 결제 방법

1. **모든 결제는 결제대행사(Groble)가 제공하는 호스팅 결제창에서만 이루어집니다.** 회원은 서비스
   화면에서 결제대행사의 결제 페이지로 이동하여 결제를 진행합니다.
2. **회사는 카드번호·유효기간·CVC·빌링키 등 결제수단 정보를 수집·저장·전송하지 않습니다.**
   해당 정보는 결제대행사가 직접 처리하며 회사의 시스템에 전달되지 않습니다.
3. 이용 가능한 결제수단은 결제대행사가 결제창에서 제공하는 범위를 따릅니다.
4. 결제 과정에서 발생하는 결제대행사 측 오류·장애·환불 처리 기준은 결제대행사의 약관을 따릅니다.

### 9.3 요금의 변경

회사가 요금을 변경하는 경우 제3조에 따라 사전 공지합니다. 회원에게 불리한 요금 변경은 적용일
30일 전에 개별 통지합니다.

## 제10조 (가맹본부에 대한 정보 제공)

1. 회원이 회원가입 시 가맹본부로부터 받은 **가맹코드를 입력**하고 회사가 이를 **승인**한 경우,
   해당 매장의 정보는 그 가맹본부의 조회 대상이 됩니다.
2. **가맹코드 입력은 선택사항입니다.** 입력하지 않아도 서비스의 모든 기능을 동일하게 이용할 수
   있으며, 이를 이유로 한 불이익은 없습니다.
3. 가맹본부에게 제공되는 정보의 범위는 다음과 같습니다.

   | 제공 항목 | 내용 |
   |----------|------|
   | 매장 정보 | 매장명, 매장 주소, 이용 상태(이용 중/정지), 플랫폼 연동 상태, 최근 수집 시각 |
   | 리뷰 | 별점, 리뷰 본문, **가명처리된 작성자 표시**, 주문 메뉴, 첨부 사진, 작성일, 수집일 |
   | 분석 결과 | 리뷰 분류, 위험도, 이슈 태그, 답글 상태 |
   | 집계 지표 | 별점·카테고리 분포, 이슈 태그 순위, 매장 간 비교, 응답 완료율 |

4. **가맹본부에게 제공하지 않는 정보**

   - 회원의 구독·청구·입금 내역 (회사와 회원 사이의 거래 정보입니다)
   - 배달 플랫폼 계정정보 일체 (아이디를 포함합니다)
   - 회원의 개인정보 (이메일, 전화번호, 사업자 정보)
   - 리뷰 작성자를 재식별할 수 있는 값

5. **가맹본부는 조회만 할 수 있습니다.** 가맹본부는 회원의 답글을 수정·승인·거절하거나 매장 설정을
   변경할 수 없습니다.
6. **가맹본부의 모든 조회는 기록됩니다.** 회사는 가맹본부가 언제 어떤 정보를 조회했는지 감사기록으로
   보관하며, 회원은 회사에 자신의 매장에 대한 조회 기록의 확인을 요청할 수 있습니다.
7. 회원은 언제든지 회사에 가맹본부 소속 해제를 요청할 수 있습니다. 해제 시 이후의 조회는 중단됩니다.

## 제11조 (계약 해지와 환불)

1. **회원의 해지** — 회원은 언제든지 서비스 화면 또는 고객문의를 통해 해지를 요청할 수 있습니다.
2. **해지 처리 절차** — 회사는 해지 요청을 접수하고, 결제대행사를 통한 정기결제 해지를 처리합니다.
   **해지 요청 접수 시점과 결제대행사 측 정기결제 중지 시점 사이에 처리 기간이 소요될 수 있습니다.**
   회사는 접수 사실과 처리 결과를 회원에게 안내합니다.
3. **해지의 효력** — 해지 시 이미 결제된 이용기간의 잔여 기간까지는 서비스를 계속 이용할 수 있으며,
   해당 기간 종료와 함께 서비스 제공이 종료됩니다.
4. **환불** — 환불 기준은 다음과 같습니다.

   | 사유 | 처리 |
   |------|------|
   | 회원의 단순 변심에 의한 중도 해지 | 이미 경과한 이용기간에 대한 요금은 환불하지 않습니다 |
   | 회사의 귀책사유로 서비스를 제공하지 못한 경우 | 제공하지 못한 기간에 해당하는 금액을 일할 계산하여 환불합니다 |
   | 회사의 서비스 종료 | 잔여 기간을 일할 계산하여 환불합니다 |

   환불은 결제대행사의 환불 절차를 통해 이루어지며, 결제수단·결제대행사 정책에 따라 처리 기간이
   달라질 수 있습니다.
5. **회사의 해지** — 회사는 회원이 제7조의 의무를 중대하게 위반하거나 요금을 연체한 경우, 시정을
   최고한 뒤에도 시정되지 않으면 이용계약을 해지할 수 있습니다.
6. 해지 후 회원 정보와 수집된 데이터의 보관·파기는 **개인정보처리방침(문서 17)**을 따릅니다.

## 제12조 (서비스의 중단과 변경)

1. 회사는 다음의 경우 서비스의 전부 또는 일부를 일시 중단할 수 있습니다.
   - 설비 보수·점검·교체·고장 등 운영상 필요한 경우
   - 정전, 통신 두절, 천재지변 등 불가항력이 발생한 경우
   - 배달 플랫폼 또는 회사가 이용하는 외부 서비스의 장애·정책 변경이 있는 경우
2. 정기 점검은 사전 공지하며, 긴급한 사유가 있는 경우 사후에 공지할 수 있습니다.
3. 회사는 서비스의 내용을 변경할 수 있으며, 중요한 변경은 제3조에 따라 사전 공지합니다.
4. 회사가 서비스를 종료하는 경우 종료일 **30일 전**에 공지하고 제11조에 따라 정산합니다.

## 제13조 (회사의 면책)

1. 회사는 다음의 사유로 발생한 손해에 대하여 책임지지 않습니다. 다만 회사의 **고의 또는 중대한
   과실**이 있는 경우는 그러하지 아니합니다.
   - 천재지변, 전쟁, 폭동 등 불가항력
   - 배달 플랫폼의 장애·정책 변경·서비스 종료
   - 회사가 이용하는 외부 서비스 제공자(데이터 연동 서비스, 결제대행사 등)의 장애
   - 회원이 제공한 계정정보의 오류·변경·만료
   - 회원 또는 제3자가 서비스를 통하지 않고 직접 게시한 내용
   - 회원의 배달 플랫폼 정책 위반
2. 회사는 서비스를 통해 게시된 답글로 인해 회원과 리뷰 작성자 또는 제3자 사이에 발생한 분쟁에
   개입할 의무가 없으며, 그로 인한 손해를 배상할 책임이 없습니다. 다만 그 답글이 회사의 고의 또는
   중대한 과실로 생성된 경우는 그러하지 아니합니다.
3. 회사는 서비스 이용으로 회원이 기대하는 매출 증대, 별점 개선, 리뷰 수 증가 등의 결과를 보증하지
   않습니다.
4. **회사의 배상책임은 그 사유가 발생한 시점을 기준으로 직전 3개월간 해당 회원이 회사에 지급한
   이용요금 총액을 한도로 합니다.** 다만 회사의 고의 또는 중대한 과실, 생명·신체에 대한 손해,
   개인정보 유출로 인한 손해에는 이 한도를 적용하지 않습니다.

## 제14조 (지식재산권)

1. 서비스 및 서비스에 포함된 소프트웨어·화면·문서에 대한 지식재산권은 회사에 귀속합니다.
2. 회원이 등록한 매장 정보와 회원이 직접 입력한 답글 형식·문구에 대한 권리는 회원에게 있습니다.
3. **서비스가 생성한 답글의 이용 권한은 회원에게 있습니다.** 회원은 해당 답글을 자유롭게 이용할 수
   있습니다.
4. 회사는 서비스 개선을 위하여 회원의 매장에서 수집된 데이터를 **개별 매장·개인을 식별할 수 없는
   형태로 가공하여** 통계·모델 개선에 이용할 수 있습니다. 구체적 범위는 개인정보처리방침을 따릅니다.
5. 회원은 회사의 사전 서면 동의 없이 서비스를 복제·역설계·개작하거나 제3자에게 재판매할 수 없습니다.

## 제15조 (분쟁 해결과 관할)

1. 회사와 회원 사이에 분쟁이 발생한 경우 상호 협의하여 해결하도록 노력합니다.
2. 이 약관은 대한민국 법령에 따라 해석됩니다.
3. 서비스 이용과 관련한 소송의 관할법원은 〇〇법원으로 합니다.

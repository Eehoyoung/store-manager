## 1. 총칙

〇〇(이하 "회사")는 정보주체의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관계 법령을
준수합니다. 회사는 이 방침을 통해 어떤 개인정보를 어떤 목적으로 처리하고 어떻게 보호하는지
알려드립니다.

**이 서비스는 사업자(가맹점)를 대상으로 하는 B2B 서비스입니다.** 다만 서비스의 성격상 회사는
**서비스 회원이 아닌 배달 플랫폼 리뷰 작성자의 정보도 처리**합니다. 이에 관하여는 §5에서 별도로
설명합니다.

## 2. 처리하는 개인정보 항목

### 2.1 회원(가맹점주)

| 구분 | 항목 | 수집 시점 | 필수/선택 |
|------|------|----------|:---:|
| 계정 | 이메일, 비밀번호(암호화 저장) | 회원가입 | 필수 |
| 신원 | 이름 | 회원가입 | 필수 |
| 연락처 | 전화번호 | 회원가입 | **선택** |
| 매장 | 매장명, 매장 주소 | 회원가입 | 필수 |
| 소속 | 가맹코드 | 회원가입 | **선택** (§4 참고) |
| 이용기록 | 접속 일시, 서비스 이용 기록, 감사 로그 | 서비스 이용 시 자동 | 필수 |

> **비밀번호는 복호화할 수 없는 형태(단방향 해시)로 저장**되며 회사도 원문을 알 수 없습니다.
>
> **사업자등록번호는 현재 수집하지 않습니다.** 향후 세금계산서 발행 등을 위해 수집하게 되는 경우
> 이 방침을 개정하고 별도 동의를 받습니다.

### 2.2 배달 플랫폼 계정정보 ★특별 관리 대상

| 항목 | 내용 |
|------|------|
| 수집 항목 | 배달 플랫폼 로그인 아이디, 로그인 비밀번호 |
| 수집 목적 | 회원 매장의 리뷰 조회 및 답글 등록 대행 |
| 저장 방식 | **AES-256-GCM 봉투암호화**. 비밀번호 원문은 데이터베이스·로그·오류 메시지 어디에도 저장하지 않습니다 |
| 접근 기록 | 복호화하여 사용할 때마다 **감사 로그에 기록**합니다 |
| 삭제 | 회원이 플랫폼 연동을 해제하거나 이용계약이 종료되면 파기합니다 |

> **이는 회원 본인의 계정정보이며, 회원의 위임에 따라 회사가 보관·사용합니다.**
> 회사는 이 정보를 리뷰 조회·답글 등록 외의 목적으로 사용하지 않습니다.

### 2.3 리뷰 작성자(비회원 정보주체) ★§5에서 상세 설명

| 작성자 식별값 | 닉네임에 회사 고유 비밀값을 결합한 **단방향 해시**. 동일인 판별에만 사용하며 원문 복원 불가 |

| 기존 답글 | 회원이 이전에 직접 작성한 답글 (말투 학습용) |

## 4. 개인정보의 제3자 제공

### 4.1 가맹본부에 대한 제공

| 구분 | 내용 |
|------|------|
| **제공받는 자** | 회원이 가맹계약을 체결한 프랜차이즈 가맹본부 |
| **제공 목적** | 브랜드 단위 리뷰 현황·운영 상태 파악 및 가맹점 지원 |
| **제공 근거** | **정보주체(회원)의 동의.** 회원이 회원가입 시 가맹본부로부터 받은 가맹코드를 직접 입력하고, 회사가 이를 승인한 경우에만 제공됩니다 |
| **제공 시점** | 회사가 소속 승인을 완료한 시점부터 |
| **보유·이용 기간** | 회원의 이용계약이 종료되거나 회원이 소속 해제를 요청할 때까지 |

**제공 항목**

| 분류 | 항목 |
|------|------|
| 매장 | 매장명, 매장 주소, 이용 상태(이용 중/정지), 플랫폼 연동 상태, 최근 수집 시각, 미처리·차단·고위험 건수, 최근 리뷰 수, 최근 평균 별점 |
| 리뷰 | 별점, 리뷰 본문, **가명처리된 작성자 표시**, 주문 메뉴, 첨부 사진, 작성일, 수집일 |
| 분석 | 리뷰 분류, 위험도, 위험 사유, 이슈 태그, 답글 상태 |
| 집계 | 별점·카테고리 분포, 이슈 태그 순위, 메뉴별 이슈, 일자별 추이, 매장 간 비교, 답글 완료율 |

**제공하지 않는 항목**

| 항목 | 이유 |
|------|------|
| 회원의 이메일·전화번호·사업자 정보 | 계약 주체의 개인정보 |
| 구독·청구·입금 내역 | 회사와 회원 사이의 거래 정보 |
| 배달 플랫폼 계정정보 (아이디 포함) | 자격증명 보호 |
| 리뷰 작성자 식별 해시값 | 재식별 위험 |

**제공 방식과 통제**

- 가맹본부는 **조회만 가능**하며, 어떠한 수정·생성·삭제도 할 수 없습니다.
- 가맹본부는 **자신의 브랜드에 소속 승인된 매장만** 조회할 수 있습니다.
- **가맹본부의 모든 조회는 감사 로그에 기록**됩니다. 회원은 회사에 자신의 매장에 대한 조회 기록의
  확인을 요청할 수 있습니다.

### 4.2 동의를 거부할 권리와 거부 시 불이익

**가맹코드 입력은 선택사항입니다.** 입력하지 않아도 회원은 서비스의 모든 기능(리뷰 수집, 답글
생성, 자동 게시, 조회·통계)을 **동일하게** 이용할 수 있으며, 요금에도 차이가 없습니다.
**동의를 거부함으로써 회사가 회원에게 가하는 불이익은 없습니다.**

> **다만 회원과 가맹본부 사이의 가맹계약상 별도의 의무가 있을 수 있으며, 이는 회사가 관여하지
> 않는 사항입니다.**

### 4.3 그 밖의 제3자 제공

회사는 위 경우를 제외하고 정보주체의 동의 없이 개인정보를 제3자에게 제공하지 않습니다.
다만 법령에 특별한 규정이 있거나 수사기관이 법령에 정한 절차와 방법에 따라 요구하는 경우에는
그러하지 아니합니다.

## 5. 리뷰 작성자에 대한 처리

### 5.1 처리 구조

회사는 **회원(가맹점)의 위임을 받아** 그 매장에 게시된 리뷰를 수집합니다. 리뷰 작성자는 회사의
회원이 아니며, **회사와 직접적인 접점이 없습니다.** 회사는 리뷰 작성자의 연락처를 알지 못하며
개별적으로 연락할 수단도 없습니다.

### 5.2 가명처리

**회사는 리뷰 작성자의 닉네임을 원문 그대로 저장하지 않습니다.**

| 단계 | 처리 |
|------|------|
| 1. 수집 | 배달 플랫폼에서 리뷰와 닉네임을 조회합니다. 배달의민족은 닉네임이 마스킹되지 않은 원문으로 전달됩니다 |
| 2. 가명처리 | **저장 직전에** 닉네임의 첫 글자를 제외한 나머지를 마스킹 처리합니다 (예: `히리릴` → `히**`) |
| 3. 식별값 생성 | 닉네임에 회사만 아는 비밀값을 결합하여 단방향 해시를 생성합니다. 동일인 판별에만 사용하며 원문을 복원할 수 없습니다 |
| 4. 원문 폐기 | 원문 닉네임은 저장하지 않으며, 로그·오류 메시지에도 남기지 않습니다 |

요기요·쿠팡이츠는 배달 플랫폼이 이미 마스킹한 형태로 전달하며, 회사는 그 형태를 그대로 유지합니다.

### 5.3 처리의 법적 근거에 대한 회사의 입장

**회사는 이 처리를 다음과 같이 보고 있습니다.**

1. 리뷰는 배달 플랫폼에 **공개적으로 게시된 정보**이며, 매장 운영자(회원)는 해당 플랫폼의 사장님
   화면을 통해 이를 열람할 정당한 권한을 가집니다.
2. 회사는 회원의 위임을 받아 회원이 열람할 수 있는 정보를 대신 조회·정리하는 역할을 수행합니다.
3. 리뷰에 대한 답글은 매장 운영자의 정당한 영업 활동이며, 그 준비를 위한 처리는 **계약의 이행 및
   정당한 이익**에 근거합니다.
4. 회사는 처리 범위를 최소화하기 위해 **닉네임을 저장 전 가명처리**하고, 개인을 특정할 수 있는
   원문 값을 보관하지 않습니다.

### 5.4 리뷰 작성자의 권리 행사

리뷰 작성자는 자신의 리뷰와 관련하여 회사에 열람·정정·삭제·처리정지를 요청할 수 있습니다.
다만 회사는 리뷰 작성자를 식별할 수단을 보유하지 않으므로, 요청 시 **해당 리뷰를 특정할 수 있는
정보(배달 플랫폼, 매장명, 리뷰 작성일, 리뷰 내용 등)**를 함께 제공해 주셔야 처리가 가능합니다.

**배달 플랫폼에 게시된 리뷰 원본의 삭제는 해당 배달 플랫폼에 요청하셔야 합니다.** 회사는 배달
플랫폼의 리뷰를 삭제할 권한이 없습니다.

회사는 서비스 제공을 위해 다음과 같이 개인정보 처리 업무를 위탁하고 있습니다.

### 6.1 재위탁 구조에 대한 고지 ★

**회사가 위탁받은 회원의 배달 플랫폼 계정정보는 수탁자(기웅정보통신)에게 전달되어 실제 배달
플랫폼 접속에 사용됩니다.**

```
회원 ──위임──▶ 회사 ──위탁──▶ 기웅정보통신(주) ──접속──▶ 배달 플랫폼
              (암호화 보관)      (조회·등록 대행)
```

- 회사는 수탁자에게 위탁 업무 수행에 필요한 최소한의 정보만 전달합니다.
- 회사는 수탁 계약 시 개인정보 보호 관련 의무를 명시하고 수탁자를 관리·감독합니다.
- 위탁 업무 또는 수탁자가 변경되는 경우 이 방침을 통해 공개합니다.

### 6.2 AI 처리에 관한 고지

회사는 리뷰를 분석하고 답글을 생성하기 위해 인공지능 모델을 사용합니다.

| 항목 | 현재 상태 |
|------|----------|
| 처리되는 정보 | 리뷰 본문, 별점, 주문 메뉴, 매장의 기존 답글 |
| **처리되지 않는 정보** | 회원의 개인정보, 배달 플랫폼 계정정보, 작성자 식별 해시값 |
| 처리 위치 | 〇〇 **(입력 필요 — 외부 AI 서비스 이용 시 수탁자 등재 및 국외 이전 고지 필요)** |

## 9. 정보주체의 권리와 행사 방법

### 9.1 권리

정보주체는 회사에 대하여 언제든지 다음 권리를 행사할 수 있습니다.

| 권리 | 내용 |
|------|------|
| 열람 | 자신의 개인정보 처리 현황을 확인 |
| 정정·삭제 | 사실과 다른 정보의 수정 또는 삭제 요구 |
| 처리정지 | 개인정보 처리의 중지 요구 |
| 동의 철회 | 동의에 근거한 처리(가맹본부 제공 등)에 대한 동의 철회 |

### 9.2 행사 방법

- **서비스 화면**을 통해 직접 조회·수정할 수 있는 항목: 이름, 전화번호, 비밀번호, 매장 정보
- 그 밖의 요청: 개인정보 보호책임자에게 서면·전자우편으로 요청
- 회사는 요청을 받은 날부터 **10일 이내**에 처리하고 결과를 통지합니다.
- 법정대리인 또는 위임을 받은 자를 통해서도 요청할 수 있으며, 이 경우 위임장을 제출해야 합니다.

### 9.3 가맹본부 제공에 대한 동의 철회

회원은 언제든지 회사에 **가맹본부 소속 해제**를 요청할 수 있습니다. 해제 시 이후 해당 가맹본부의
조회는 중단됩니다. 요청은 개인정보 보호책임자 또는 고객문의를 통해 접수합니다.

### 9.4 권리 행사의 제한

법령에 따라 열람·정정·삭제·처리정지가 제한되는 경우, 회사는 그 사유를 통지합니다.

## 10. 안전성 확보 조치

회사는 개인정보의 안전성 확보를 위해 다음 조치를 취하고 있습니다.

### 10.1 기술적 조치

| 조치 | 내용 |
|------|------|
| **자격증명 암호화** | 배달 플랫폼 로그인 비밀번호는 **AES-256-GCM 봉투암호화** 방식으로 저장합니다. 데이터를 암호화하는 키를 다시 상위 키로 암호화하는 이중 구조입니다 |
| **비밀번호 단방향 암호화** | 회원 비밀번호는 복호화할 수 없는 해시 형태로만 저장합니다 |
| **가명처리** | 리뷰 작성자 닉네임은 저장 전 마스킹하며, 식별값은 비밀값을 결합한 단방향 해시로만 보관합니다 |
| **전송 구간 암호화** | 모든 통신은 HTTPS로 암호화합니다 |
| **인증 토큰 보호** | 접속 토큰은 브라우저 저장소에 저장하지 않으며, 갱신 토큰은 스크립트가 접근할 수 없는 쿠키로만 전달합니다 |
| **접근 출처 제한** | 지정된 출처에서만 서비스 접근을 허용합니다 |
| **평문 로깅 금지** | 자격증명과 원문 닉네임은 로그·오류 메시지에 기록하지 않습니다 |

### 10.2 관리적 조치

| 조치 | 내용 |
|------|------|
| **접근 권한 통제** | 회원은 자신의 매장만, 가맹본부는 승인된 소속 매장만 조회할 수 있으며 요청마다 권한을 재확인합니다 |
| **가맹본부 조회 감사** | 가맹본부의 모든 조회를 **누가·언제·무엇을** 조회했는지 감사 로그로 기록합니다 |
| **자격증명 접근 감사** | 배달 플랫폼 자격증명을 복호화할 때마다 감사 로그를 남깁니다 |
| **최소 권한** | 가맹본부에는 조회 권한만 부여하며 수정 권한은 부여하지 않습니다 |
| **운영자 권한 제한** | 소속 승인 등 운영자 기능은 명시적으로 지정된 계정만 접근할 수 있습니다 |

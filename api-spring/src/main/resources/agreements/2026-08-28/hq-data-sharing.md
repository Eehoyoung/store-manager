# 가맹본부 제3자 제공 안내

문서 버전: 2026-08-28

## 가맹코드를 넣으시면 본부가 우리 매장 리뷰를 볼 수 있게 됩니다.

본부에서 받으신 가맹코드를 넣으시면, 저희가 확인한 뒤 본부에서 사장님 매장의 리뷰와 운영 현황을
**볼 수 있게** 됩니다.

| 본부가 **볼 수 있는 것** | 본부가 **볼 수 없는 것** |
|---|---|
| 매장 이름과 주소 | 사장님 이메일·전화번호 |
| 서비스 이용 중인지 / 멈춰 있는지 | 요금·결제·입금 내역 |
| 배달앱 연결 상태와 마지막으로 리뷰를 가져온 시각 | 배달앱 아이디와 비밀번호 |
| 리뷰 별점과 리뷰 내용 | 리뷰 쓴 손님이 누구인지 알 수 있는 정보 |
| 리뷰 쓴 사람 표시 (`김**` 처럼 가려진 형태) | 사장님 사업자 정보 |
| 주문한 메뉴와 리뷰 사진 | |
| 답글이 올라갔는지 / 막혔는지 | |
| 별점 평균, 자주 나오는 불만, 다른 매장과 비교한 순위 | |

**본부는 보기만 할 수 있습니다.** 본부가 사장님 답글을 고치거나, 지우거나, 매장 설정을 바꿀 수는
없습니다. 본부가 언제 무엇을 봤는지는 모두 기록에 남습니다.

## (선택) 가맹본부에 위 정보가 제공되는 것에 동의합니다.

- **제공받는 곳**: 가맹코드를 발급한 가맹본부
- **제공 목적**: 브랜드 전체 리뷰 현황 파악과 가맹점 지원
- **제공 항목**: 위 표의 '본부가 볼 수 있는 것'
- **제공 기간**: 서비스를 이용하시는 동안. 사장님이 요청하시면 언제든 중단합니다

**동의하지 않으셔도 됩니다.** 가맹코드를 넣지 않으셔도 리뷰 수집, 답글 자동 생성, 자동 게시 등
**서비스의 모든 기능을 똑같이** 쓰실 수 있고 요금도 같습니다. 저희가 드리는 불이익은 없습니다.

다만 본부와 맺으신 가맹계약에 별도로 정해진 내용이 있을 수 있으며, 그 부분은 저희가 관여하지
않습니다.

나중에 마음이 바뀌시면 고객문의로 **소속 해제**를 요청하실 수 있습니다.
